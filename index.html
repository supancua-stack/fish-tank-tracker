ต้องสร้างโปรเจกต์ Supabase และตั้งค่าตามไฟล์ README ก่อน ข้อมูลจะไม่ออนไลน์จนกว่าจะตั้งค่าและเข้าสู่ระบบสำเร็จ
ยังไม่ได้ตั้งค่าฐานข้อมูลออนไลน์

เพื่อป้องกันข้อมูลทับกัน การส่งข้อมูลขึ้นและโหลดข้อมูลทำแบบกดปุ่มเอง ระบบจะไม่ซิงก์อัตโนมัติในเวอร์ชันนี้ โปรดส่งออก JSON สำรองก่อนเริ่มใช้งานออนไลน์ ห้ามใส่ service_role key ในเว็บไซต์
